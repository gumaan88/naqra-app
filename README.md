# منصة نَقْرَأ (Naqra App)

منصة ويب عربية تعليمية مخصصة للأطفال تساعد الطفل على قراءة الكلمات والتعرف على حروفها وربط الكلمات بالصور بطريقة ممتعة ومحفزة.

- **الدومين المباشر**: [https://naqra.gumaan.app](https://naqra.gumaan.app)
- **المكدس التقني**: React 18 + TypeScript + Vite + Tailwind CSS + Cloudflare Workers + Hono + Cloudflare D1 (SQLite) + Workers AI.
- **التصميم والمعمارية**: Local-first بدون استدعاء للخادم مع كل نقرة، حفظ الأسئلة والنتائج محلياً في `IndexedDB`، ومزامنة مجمعة `Batch Sync` مع آلية `Idempotency`.

---

## 🎮 الألعاب المضمنة

1. **حروف الكلمة**: قراءة الكلمة كاملة وتحديد حروفها بالترتيب، معالجة الحروف المكررة كبطاقات مستقلة، حروف مشتتة، ومساعدة ذكية بعد 3 أخطاء متتالية، وبدء مؤقت الحل الفعلي عند أول نقرة.
2. **الكلمة والصورة**: قراءة الكلمة واختيار الصورة المطابقة لها من بين 3 صور واضحة وجميلة، مع مؤشرات نجاح وتشجيع مستمر.

---

## 👨‍👩‍👧‍👦 لوحة ولي الأمر والتحليلات

- إدارة ملفات الأطفال برمز سري محلي وأيقونات طفولية.
- قياس دقيق للدقة الإجمالية، وقت اللعب الفعلي، والزمن الوسيط للحل (Median Solve Time).
- قوائم الكلمات المتقنة والكلمات التي تحتاج تدريباً إضافياً.
- تحليل تكرار أخطاء الحروف لمساعدة الطفل على تجاوز الصعوبات.
- خالية تماماً من الإعلانات ومن المقارنات السلبية بين الأطفال.

---

## 🛡️ لوحة مدير النظام (Admin Content Studio)

- استعراض بنك الكلمات والصور وتصنيفها بحسب المستويات (1 إلى 5).
- توليد دفعات كلمات جديدة بالذكاء الاصطناعي Cloudflare Workers AI مع التحقق الآلي والاعتماد.
- مراجعة واعتماد أو رفض الكلمات وحفظ الصور بجودة متجهة عالية.

---

## 🚀 التشغيل والتطوير المحلي

```bash
# تثبيت التبعيات
npm install

# تطبيق ترحيل قاعدة البيانات محلياً
npm run d1:migrate:local
npm run d1:seed:local

# تشغيل خادم التطوير
npm run dev

# تشغيل اختبارات الوحدة (Vitest)
npm test

# بناء حزمة الإنتاج
npm run build

# النشر على Cloudflare
npm run deploy
```
